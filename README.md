# 🌿 GreenScan – Plant Identification & Verification System

## 🚀 Overview

GreenScan is an AI-powered project that helps users **identify and verify plants using images**.
Instead of just telling *what plant it is*, this system focuses on answering:

> “Is this the plant I’m actually looking for?”

---

## 💡 Key Idea

Many plant identification tools exist, but they often:

* Lack accuracy in real-world conditions
* Don’t help in confirming a specific plant
* Provide generic information

GreenScan aims to solve this by introducing a **verification-based approach**.

---

## ✨ Features (Planned)

* 🌿 **Plant Identification**

  * Upload or scan an image to identify plant species

* 🎯 **Verification Mode (Core Feature)**

  * Check if the scanned plant matches a selected plant

* 📊 **Confidence Score**

  * Shows how accurate the prediction is

* 📖 **Useful Plant Information**

  * Medicinal uses
  * Edibility / toxicity
  * Local names

* 📸 **Real-world Image Support**

  * Designed to work with actual camera images
